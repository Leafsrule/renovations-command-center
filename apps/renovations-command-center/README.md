# Renovations Command Center

Independent Next.js/Firebase renovation app. Run all npm commands from this directory.

Copy `.env.example` to `.env.local` and supply this app’s existing Firebase configuration. Never commit environment files. Site Control credentials and records must not be used here. Production backend and web host access must be verified before deployment.

Product requirements: `docs/Renovations_Command_Center.md`. RACP Rev02 supersedes old routine owner-approval checkpoints and requires release scope A–I; older phase documents describe historical decisions.
